The second series is the University of Michigan Index of Consumer Sentiment (UMCSENT), a monthly survey of how US households see current and future economic conditions. The question is whether consumer sentiment carries information about future industrial production.

Cointegration (Johansen test)

Industrial production is not seasonally adjusted, so both the cointegration test and the VAR include monthly (seasonal) dummy variables (season = 12). Without them, the seasonal pattern ends up in the residuals and distorts the tests. The lag order of the levels VAR used by the Johansen test is chosen with the Akaike information criterion (AIC).

With K = 3 lags, for r = 0 both the trace statistic (16.37) and the maximum eigenvalue statistic (11.51) are below their 5% critical values (19.96 and 15.67). The null hypothesis r = 0 cannot be rejected: there is no cointegrating relationship, so no stable long-run link between industrial production and consumer sentiment. A VECM is therefore not estimated; instead, a VAR is fitted to the first differences of both series to make them stationary.

VAR lag selection and estimation

The VAR is estimated on the first differences with a constant and monthly dummies. The lag order should leave residuals free of autocorrelation; otherwise the Granger tests and the impulse response bands are not reliable. The table below shows the Portmanteau test for every lag order from 1 to 12.

The Schwarz and Hannan-Quinn criteria choose 2 lags, but with fewer than 12 lags the residuals remain autocorrelated at the 5% level. The AIC choice, p = 12, removes the autocorrelation and is used below. Twelve lags of monthly data cover one full year, which is plausible for a non-seasonally adjusted series.

  2. UMCSENT_d → IPB_d: the joint p-value for the 12 lags is 0.0029 (< 0.05), so the null hypothesis of no Granger causality is rejected: past changes in consumer sentiment help predict changes in industrial production.

The relationship is one-directional: sentiment helps to predict industrial production, but not the other way round. Granger causality is about predictive content, not about economic causation.

Note

In an earlier version of this analysis, the VAR had 4 lags and no seasonal dummies; its residuals were autocorrelated and the Granger test for UMCSENT_d → IPB_d was not significant (p = 0.18). Accounting for seasonality and choosing the lag order so that the residuals are clean changes this result.

Robustness: variable ordering and cumulative effect

The impulse responses above are orthogonalised with a Cholesky decomposition, which requires an ordering of the variables. With industrial production first, a sentiment shock cannot move production in the same month by construction. Below, the VAR is re-estimated with sentiment first, and the cumulative responses are computed: since the VAR is in first differences, the cumulative response of IPB_d is the effect on the level of the index.

Does sentiment improve forecasts out of sample?

The Granger test uses the whole sample. A stricter, practical question is whether sentiment improves real forecasts. The VAR is compared with:

  • an AR(12) model for the change in industrial production with the same constant and monthly dummies, i.e. the VAR equation for IPB_d without the lags of sentiment. The only difference between the two models is the information in consumer sentiment;
  • the SARIMA model from the univariate analysis, ARIMA(3,1,0)(0,1,1)[12] on log data.

As in the univariate rolling-origin evaluation, every month from June 2016 to March 2025 the three models are re-estimated on the data available up to that month and forecast industrial production 1 to 12 months ahead. Forecasts of monthly changes are added up to give index levels.

Code 
n_obs <- length(ip_ts)
n_train <- floor(0.75 * n_obs)  # same split as the univariate analysis (June 2016)
max_h <- 12

ip_values <- as.numeric(ip_ts)
ip_diff <- ts(diff(ip_values), start = c(1990, 2), frequency = 12)
umc_diff <- diff(as.numeric(umc_ts))

oos_errors <- list(
  VAR = matrix(NA, n_obs, max_h),
  `AR(12), no sentiment` = matrix(NA, n_obs, max_h),
  SARIMA = matrix(NA, n_obs, max_h)
)

for (t in n_train:(n_obs - 1)) {
  m <- t - 1                        # differences available at origin t
  steps <- 1:min(max_h, n_obs - t)  # horizons with an observed outcome
  actual <- ip_values[t + steps]

  # VAR with sentiment
  v <- VAR(data.frame(IPB_d = ip_diff[1:m], UMCSENT_d = umc_diff[1:m]),
           p = var_p, type = "const", season = 12)
  fc_var <- predict(v, n.ahead = max_h)$fcst$IPB_d[, "fcst"]

  # Same equation without sentiment; CSS gives least-squares estimates like the VAR
  x <- window(ip_diff, end = time(ip_diff)[m])
  ar <- Arima(x, order = c(var_p, 0, 0), xreg = seasonaldummy(x), method = "CSS")
  fc_ar <- forecast(ar, h = max_h, xreg = seasonaldummy(x, h = max_h))$mean

  # SARIMA on log data (median forecast)
  s <- Arima(ts(ip_values[1:t], start = c(1990, 1), frequency = 12),
             order = c(3, 1, 0), seasonal = c(0, 1, 1), lambda = 0)
  fc_sarima <- forecast(s, h = max_h)$mean

  oos_errors$VAR[t, steps] <- actual - (ip_values[t] + cumsum(fc_var))[steps]
  oos_errors$`AR(12), no sentiment`[t, steps] <- actual - (ip_values[t] + cumsum(as.numeric(fc_ar)))[steps]
  oos_errors$SARIMA[t, steps] <- actual - as.numeric(fc_sarima)[steps]
}

Clark-West test for nested models

The VAR and the AR(12) model are nested: the AR model is the VAR equation with the sentiment coefficients set to zero. If sentiment has no predictive value, both models estimate the same thing, but the VAR also estimates 12 coefficients whose true value is zero; this estimation noise makes its forecasts slightly worse even when sentiment is useful. The Diebold-Mariano test compares raw squared errors, so for nested models it is biased towards the smaller model and rarely rejects equal accuracy.

The Clark-West (2007) test corrects the squared errors of the larger model for this noise, by adding back the squared difference between the two forecasts. It is one-sided: the alternative hypothesis is that the VAR forecasts better than the AR model. For 12-month forecasts the standard error accounts for the overlap between consecutive forecasts (Newey-West with 11 lags).

Code 
clark_west <- function(e_small, e_large, h) {
  ok <- !is.na(e_small) & !is.na(e_large)
  es <- e_small[ok]
  el <- e_large[ok]
  # Forecast difference: y_hat_small - y_hat_large = e_large - e_small
  adjusted <- es^2 - (el^2 - (es - el)^2)
  fit <- lm(adjusted ~ 1)
  se <- if (h == 1) {
    sqrt(vcov(fit)[1, 1])
  } else {
    sqrt(sandwich::NeweyWest(fit, lag = h - 1, prewhite = FALSE, adjust = TRUE)[1, 1])
  }
  stat <- unname(coef(fit)[1] / se)
  data.frame(
    Horizon = paste(h, if (h == 1) "month" else "months"),
    Forecasts = sum(ok),
    `CW statistic` = round(stat, 3),
    `p-value (one-sided)` = round(1 - pnorm(stat), 3),
    check.names = FALSE
  )
}

cw_table <- do.call(rbind, lapply(c(1, 3, 6, max_h), function(k) {
  clark_west(oos_errors$`AR(12), no sentiment`[, k], oos_errors$VAR[, k], k)
}))
cw_table
  1. Adding sentiment does not improve the forecasts. One month ahead the VAR and the AR model without sentiment have practically the same RMSE (2.14 and 2.15; Diebold-Mariano p = 0.94). Twelve months ahead the VAR is slightly worse (6.69 against 6.54), but the difference is not significant (p = 0.38).
  2. The Clark-West test, which is designed for nested models, gives the same answer: the one-sided p-values range from 0.19 to 0.87, so at no horizon does the VAR forecast significantly better than the model without sentiment.
  3. The VAR is not more accurate than SARIMA at any of the horizons shown; at 1 and 12 months the differences are not statistically significant.

Sentiment is a statistically significant predictor in sample (Granger test), but this does not translate into better out-of-sample forecasts. A likely reason is that estimating 12 extra sentiment coefficients adds noise that offsets the small amount of information they carry. This is a common result in macroeconomic forecasting: in-sample significance is a weak guide to forecasting value.

The comparison uses the latest revised data, not the data that were available in real time at each forecast origin.

(`r format(zoo::as.yearmon(time(umc_ts)[which.min(umc_ts)]))`).

## Cointegration (Johansen test)

Industrial production is not seasonally adjusted, so both the cointegration
test and the VAR include **monthly (seasonal) dummy variables**
(`season = 12`). Without them, the seasonal pattern ends up in the residuals
and distorts the tests. The lag order of the levels VAR used by the Johansen
test is chosen with the Akaike information criterion (AIC).

```{r}
#| label: johansen

lag_select$selection

johansen_trace <- ca.jo(dset, type = "trace", ecdet = "const", K = johansen_k, season = 12)
johansen_eigen <- ca.jo(dset, type = "eigen", ecdet = "const", K = johansen_k, season = 12)
```

```{r}
#| label: tbl-johansen

jo_eigen <- johansen_table(johansen_eigen)

```

With K = `r johansen_k` lags, for r = 0 both the trace statistic (`r jo_trace$Statistic[2]`) and the maximum
eigenvalue statistic (`r jo_eigen$Statistic[2]`) are below their 5% critical
values (`r jo_trace[["5pct"]][2]` and `r jo_eigen[["5pct"]][2]`). The null
hypothesis r = 0 cannot be rejected: there is no cointegrating relationship, so
no stable long-run link between industrial production and consumer sentiment.
A VECM is therefore not estimated; instead, a VAR is fitted to the first
differences of both series to make them stationary.

### Robustness: variable ordering and cumulative effect

The impulse responses above are *orthogonalised* with a Cholesky
decomposition, which requires an ordering of the variables. With industrial
production first, a sentiment shock cannot move production in the same month
by construction. Below, the VAR is re-estimated with sentiment first, and the
**cumulative** responses are computed: since the VAR is in first differences,
the cumulative response of `IPB_d` is the effect on the *level* of the index.

```{r}
#| label: irf-robustness
var_model_rev <- VAR(dset_diff[, c("UMCSENT_d", "IPB_d")], p = var_p, type = "const", season = 12)

set.seed(123)
irf_rev <- irf(var_model_rev, impulse = "UMCSENT_d", response = "IPB_d",
               n.ahead = 12, boot = TRUE, ci = 0.90)

cumulative_irf <- function(model) {
  set.seed(123)
  irf(model, impulse = "UMCSENT_d", response = "IPB_d",
      n.ahead = 12, boot = TRUE, ci = 0.90, cumulative = TRUE)
}
cum_base <- cumulative_irf(var_model)
cum_rev <- cumulative_irf(var_model_rev)

# Size of a one-standard-deviation orthogonal sentiment shock, in index points

  chol_factor <- t(chol(summary(model)$covres))
  chol_factor[var, var]
```

## Does sentiment improve forecasts out of sample?

The Granger test uses the whole sample. A stricter, practical question is
whether sentiment improves **real forecasts**. The VAR is compared with:

- an **AR(12) model** for the change in industrial production with the same
  constant and monthly dummies, i.e. the VAR equation for `IPB_d` *without*
  the lags of sentiment. The only difference between the two models is the
  information in consumer sentiment;
- the **SARIMA** model from the [univariate analysis](univariate.qmd),
  ARIMA(3,1,0)(0,1,1)[12] on log data.

As in the univariate rolling-origin evaluation, every month from June 2016 to
March 2025 the three models are re-estimated on the data available up to that
month and forecast industrial production 1 to 12 months ahead. Forecasts of
monthly changes are added up to give index levels.

```{r}

  steps <- 1:min(max_h, n_obs - t)  # horizons with an observed outcome

  # VAR with sentiment
  v <- VAR(data.frame(IPB_d = ip_diff[1:m], UMCSENT_d = umc_diff[1:m]),
           p = var_p, type = "const", season = 12)
  fc_var <- predict(v, n.ahead = max_h)$fcst$IPB_d[, "fcst"]

  # Same equation without sentiment; CSS gives least-squares estimates like the VAR

  ar <- Arima(x, order = c(var_p, 0, 0), xreg = seasonaldummy(x), method = "CSS")
  fc_ar <- forecast(ar, h = max_h, xreg = seasonaldummy(x, h = max_h))$mean

  # SARIMA on log data (median forecast)

             order = c(3, 1, 0), seasonal = c(0, 1, 1), lambda = 0)
  fc_sarima <- forecast(s, h = max_h)$mean

  oos_errors$`AR(12), no sentiment`[t, steps] <- actual - (ip_values[t] + cumsum(as.numeric(fc_ar)))[steps]
  oos_errors$SARIMA[t, steps] <- actual - as.numeric(fc_sarima)[steps]
```

### Clark-West test for nested models

The VAR and the AR(12) model are **nested**: the AR model is the VAR equation
with the sentiment coefficients set to zero. If sentiment has no predictive
value, both models estimate the same thing, but the VAR also estimates 12
coefficients whose true value is zero; this estimation noise makes its
forecasts slightly worse even when sentiment is useful. The Diebold-Mariano
test compares raw squared errors, so for nested models it is biased towards
the smaller model and rarely rejects equal accuracy.

The Clark-West (2007) test corrects the squared errors of the larger model for
this noise, by adding back the squared difference between the two forecasts.
It is one-sided: the alternative hypothesis is that the VAR forecasts better
than the AR model. For 12-month forecasts the standard error accounts for the
overlap between consecutive forecasts (Newey-West with 11 lags).

```{r}
#| label: tbl-clark-west
#| tbl-cap: "Clark-West tests, VAR (with sentiment) vs AR(12) (without sentiment)"
clark_west <- function(e_small, e_large, h) {
  ok <- !is.na(e_small) & !is.na(e_large)
  es <- e_small[ok]
  el <- e_large[ok]
  # Forecast difference: y_hat_small - y_hat_large = e_large - e_small
  adjusted <- es^2 - (el^2 - (es - el)^2)
  fit <- lm(adjusted ~ 1)
  se <- if (h == 1) {
    sqrt(vcov(fit)[1, 1])
  } else {
    sqrt(sandwich::NeweyWest(fit, lag = h - 1, prewhite = FALSE, adjust = TRUE)[1, 1])
  }
  stat <- unname(coef(fit)[1] / se)
  data.frame(
    Horizon = paste(h, if (h == 1) "month" else "months"),
    Forecasts = sum(ok),
    `CW statistic` = round(stat, 3),
    `p-value (one-sided)` = round(1 - pnorm(stat), 3),
    check.names = FALSE
  )
}

cw_table <- do.call(rbind, lapply(c(1, 3, 6, max_h), function(k) {
  clark_west(oos_errors$`AR(12), no sentiment`[, k], oos_errors$VAR[, k], k)
}))
cw_table
```

1. **Adding sentiment does not improve the forecasts.** One month ahead the VAR
   and the AR model without sentiment have practically the same RMSE
   (`r sprintf("%.2f", oos_table[1, "1 month"])` and
   `r sprintf("%.2f", oos_table[2, "1 month"])`; Diebold-Mariano
   p = `r sprintf("%.2f", dm_var_ar("1 month"))`). Twelve months ahead the VAR is
   slightly worse (`r sprintf("%.2f", oos_table[1, "12 months"])` against
   `r sprintf("%.2f", oos_table[2, "12 months"])`), but the difference is not
   significant (p = `r sprintf("%.2f", dm_var_ar("12 months"))`).
2. The Clark-West test, which is designed for nested models, gives the same
   answer: the one-sided p-values range from
   `r sprintf("%.2f", min(cw_table[["p-value (one-sided)"]]))` to
   `r sprintf("%.2f", max(cw_table[["p-value (one-sided)"]]))`, so at no horizon
   does the VAR forecast significantly better than the model without sentiment.
3. The VAR is not more accurate than SARIMA at any of the horizons shown; at 1
   and 12 months the differences are not statistically significant.

Sentiment is a statistically significant predictor *in sample* (Granger test),
but this does not translate into better *out-of-sample* forecasts. A likely
reason is that estimating 12 extra sentiment coefficients adds noise that
offsets the small amount of information they carry. This is a common result in macroeconomic
forecasting: in-sample significance is a weak guide to forecasting value.

The comparison uses the latest revised data, not the data that were available
in real time at each forecast origin.

## VAR forecast

```{r}
#| label: fig-var-forecast
#| fig-cap: "VAR forecast of industrial production, 24 months ahead (dashed line = end of data)"
var_forecast <- predict(var_model, n.ahead = 24, ci = 0.90)

fc_ipb_diff <- var_forecast$fcst$IPB_d[, "fcst"]

# Rebuild index levels by adding the forecast changes to the last observed value
last_ipb <- tail(as.numeric(ip_ts), 1)
fc_ipb_level <- cumsum(c(last_ipb, fc_ipb_diff))[-1]

history_time <- as.numeric(time(ip_ts))
last_time_point <- tail(history_time, 1)
forecast_time <- seq(last_time_point + 1 / 12, by = 1 / 12, length.out = length(fc_ipb_level))

df_ipb <- data.frame(
  time = c(history_time, forecast_time),
  value = c(as.numeric(ip_ts), fc_ipb_level)
)

ggplot(df_ipb, aes(x = time, y = value)) +
  geom_line() +
  geom_vline(xintercept = last_time_point, linetype = "dashed", colour = "red") +
  labs(x = "Year", y = "Index (2017 = 100)")
```

1. `predict()` forecasts the next 24 months with a 90% interval.
2. Because the VAR is estimated on differences, the forecasts are monthly
   changes.
3. They are converted back to index levels with `cumsum()`, adding the forecast
   changes to the last observed value (`r round(last_ipb, 2)`).
4. To the right of the dashed red line, the forecast reproduces the seasonal
   pattern through the monthly dummies. On average it stays around
   `r round(mean(fc_ipb_level), 1)` index points over the 24 months and ends at
   `r round(tail(fc_ipb_level, 1), 2)`, close to the recent level of the series.
