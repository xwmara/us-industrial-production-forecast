This project forecasts the monthly US Industrial Production Index (1990–2025) and tests whether consumer sentiment helps to anticipate it. It compares classical time series models on a held-out test period, from data preparation and statistical testing to model diagnostics and a rolling-origin backtest.

Key findings

  • The series needs transforming before modelling. Industrial production has a trend, a strong seasonal pattern and two large shocks (2008–2009 and 2020). Unit root tests (KPSS, ADF, Phillips-Perron) agree that it is non-stationary; the HEGY test shows a stochastic trend (p = 0.43) but a deterministic seasonal pattern (seasonal unit roots rejected, p < 0.01).
  • No model clearly wins. With a single forecast origin (June 2016), SARIMA looked best (RMSE 2.93). A rolling-origin evaluation, which re-estimates the models every month, is more reliable: SARIMA, ETS and Holt-Winters are statistically tied one month ahead (RMSE 1.96–2.07) and all significantly beat a seasonal naive benchmark (4.11). From about 4 months ahead the seasonal naive forecast has a lower RMSE, but the difference is not statistically significant at any horizon (Diebold-Mariano p ≥ 0.29).
  • Consumer sentiment has statistically significant but small predictive content. The two series are not cointegrated. In a VAR with seasonal dummies, sentiment Granger-causes industrial production (p = 0.003) but not the reverse (p = 0.42), and it explains about 5% of production’s forecast variance. A typical sentiment shock (about 4 points) raises the production index by about 0.4–0.5 points over a year. Adding sentiment to the model does not improve out-of-sample forecasts: neither the Diebold-Mariano test nor the Clark-West test for nested models finds a gain (Clark-West one-sided p between 0.19 and 0.87).
  • Outlook: a SARIMA model re-estimated on all data forecasts the index at around 100–102 through April 2028 (95% interval 84–120).

Takeaway: one month ahead, any of the three statistical models clearly beats a naive benchmark; from about 4 months ahead a naive seasonal forecast has lower errors, although not significantly, so the models add clear value only at the shortest horizon. Consumer sentiment helps at the margin in sample, but not enough to improve forecasts.

Limitations

  • Prediction intervals are probably too narrow in crises. Model residuals show ARCH effects (volatility clustering) and heavy tails, while the intervals assume constant, normal errors.
  • The pandemic dominates the errors. A few months in 2020 produce the largest forecast errors; results excluding them are reported as a robustness check, and the main conclusions do not change.
  • Revised data, not real-time data. The backtest uses the data as revised by December 2025, not the figures available to a forecaster at each date.
  • One series and one sample. The conclusions apply to this index and this period.
  • Seasonal differencing is a modelling choice. The HEGY test points to deterministic seasonality; a model with a first difference and monthly dummies was not tested as a forecasting alternative to SARIMA.

How the analysis is organised

  • Univariate models: visual analysis, stationarity and seasonality tests, ARMA, SARIMA, ETS, Holt-Winters, a seasonal naive benchmark, residual diagnostics, single-origin and rolling-origin evaluation, and the forecast to 2028.
  • VAR analysis: consumer sentiment, Johansen cointegration test, VAR with seasonal dummies, Granger causality, impulse responses, variance decomposition, an out-of-sample test of the value of sentiment (Diebold-Mariano and Clark-West) and a 24-month forecast.

About

This is a portfolio adaptation of a team project for the Time Series course at the Bucharest University of Economic Studies (2025). The analysis was reviewed and extended for this version: the forecast evaluation, the VAR specification and several tests were corrected, and an out-of-sample test of consumer sentiment was added. See the README for credits.

## Key findings

- **The series needs transforming before modelling.** Industrial production has
  a trend, a strong seasonal pattern and two large shocks (2008–2009 and 2020).
  Unit root tests (KPSS, ADF, Phillips-Perron) agree that it is non-stationary;
  the HEGY test shows a stochastic trend (p = `r f2(uni$hegy_t1_p)`) but a
  deterministic seasonal pattern (seasonal unit roots rejected, p < 0.01).
- **No model clearly wins.** With a single forecast origin (June 2016), SARIMA
  looked best (RMSE `r f2(uni$single_origin["SARIMA", "RMSE"])`). A
  rolling-origin evaluation, which re-estimates the models every month, is more
  reliable: SARIMA, ETS and Holt-Winters are statistically tied one month ahead
  (RMSE `r f2(min(cv_rmse_1[stat_models]))`–`r f2(max(cv_rmse_1[stat_models]))`)
  and all significantly beat a seasonal naive benchmark
  (`r f2(cv_rmse_1["Seasonal naive"])`). From about `r naive_lower_from` months
  ahead the seasonal naive forecast has a lower RMSE, but the difference is not
  statistically significant at any horizon (Diebold-Mariano p ≥ `r floor(100 * min(naive_p_after)) / 100`).
- **Consumer sentiment has statistically significant but small predictive
  content.** The two series are not cointegrated. In a VAR with seasonal
  dummies, sentiment Granger-causes industrial production
  (p = `r sprintf("%.3f", mv$granger_umc_p)`) but not the reverse
  (p = `r f2(mv$granger_ipb_p)`), and it explains about
  `r round(100 * mv$fevd_10["IPB_d", "UMCSENT_d"])`% of production's forecast
  variance. A typical sentiment shock (about `r round(mv$shock_size)` points)
  raises the production index by about
  `r f1(min(mv$cum_irf_12))`–`r f1(max(mv$cum_irf_12))` points over a year.
  Adding sentiment to the model **does not improve out-of-sample forecasts**:
  neither the Diebold-Mariano test nor the Clark-West test for nested models
  finds a gain (Clark-West one-sided p between `r f2(min(cw_p))` and
  `r f2(max(cw_p))`).
- **Outlook:** a SARIMA model re-estimated on all data forecasts the index at
  around `r round(min(fut$forecast))`–`r round(max(fut$forecast))`
  through `r fut_last$month` (95% interval `r round(fut_last$lower95)`–`r round(fut_last$upper95)`).
