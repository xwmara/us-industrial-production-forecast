SARIMA, exponential smoothing and a VAR with consumer sentiment

Code 
source("R/setup.R")

This project forecasts the monthly US Industrial Production Index (1990–2025) and tests whether consumer sentiment helps to anticipate it. It compares classical time series models on a held-out test period, from data preparation and statistical testing to model diagnostics and a rolling-origin backtest.

Code 
autoplot(ip_ts) +
  labs(x = NULL, y = "Index (2017 = 100)")

Key findings

  • The series needs transforming before modelling. Industrial production has a trend, a strong seasonal pattern and two large shocks (2008–2009 and 2020). Unit root tests (KPSS, ADF, Phillips-Perron) agree that it is non-stationary; the HEGY test shows a stochastic trend but a deterministic seasonal pattern.
  • No model clearly wins. With a single forecast origin (June 2016), SARIMA looked best (RMSE 2.93). A rolling-origin evaluation, which re-estimates the models every month, is more reliable: SARIMA, ETS and Holt-Winters are statistically tied one month ahead (RMSE about 2.0) and all beat a seasonal naive benchmark (4.1). From about four months ahead, simply repeating last year’s values is as accurate as any model.
  • Consumer sentiment has statistically significant but small predictive content. The two series are not cointegrated. In a VAR with seasonal dummies, sentiment Granger-causes industrial production (p = 0.003) but not the reverse, and it explains about 5% of production’s forecast variance. A typical sentiment shock raises the production index by about 0.4–0.5 points over a year. Adding sentiment to the model does not improve out-of-sample forecasts.
  • Outlook: a SARIMA model re-estimated on all data forecasts the index at around 100–102 through April 2028 (95% interval 84–120).

Takeaway: for forecasts up to about three months, any of the three statistical models clearly beats a naive benchmark; beyond that, a naive seasonal forecast is hard to beat. Consumer sentiment helps at the margin in sample, but not enough to improve forecasts.

Limitations

  • Prediction intervals are probably too narrow in crises. Model residuals show ARCH effects (volatility clustering) and heavy tails, while the intervals assume constant, normal errors.
  • The pandemic dominates the errors. A few months in 2020 produce the largest forecast errors; results excluding them are reported as a robustness check, and the main conclusions do not change.
  • Revised data, not real-time data. The backtest uses the data as revised by December 2025, not the figures available to a forecaster at each date.
  • One series and one sample. The conclusions apply to this index and this period.
  • Seasonal differencing is a modelling choice. The HEGY test points to deterministic seasonality; a model with a first difference and monthly dummies was not tested as a forecasting alternative to SARIMA.

How the analysis is organised

  • Univariate models: visual analysis, stationarity and seasonality tests, ARMA, SARIMA, ETS, Holt-Winters, a seasonal naive benchmark, residual diagnostics, single-origin and rolling-origin evaluation, and the forecast to 2028.
  • VAR analysis: consumer sentiment, Johansen cointegration test, VAR with seasonal dummies, Granger causality, impulse responses, variance decomposition, an out-of-sample test of the value of sentiment and a 24-month forecast.

Tools

R (forecast, urca, tseries, uroot, lmtest, FinTS, vars), Quarto for the report and renv for package versions.

About

This is a portfolio adaptation of a team project for the Time Series course at the Bucharest University of Economic Studies (2025). The analysis was reviewed and extended for this version: the forecast evaluation, the VAR specification and several tests were corrected, and an out-of-sample test of consumer sentiment was added. See the README for credits.
